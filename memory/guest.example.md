## 记录规则

| 记什么 | 不记什么 |
|---|---|
| 客人亲口说过的事 | 你推测的事 |
| 你的原话承诺 | 你觉得他可能想要的东西 |
| 具体的时间、地点、人物 | 模板填空式的空话 |

**记了不等于要用。** Version 1.0 只用它来让开场问候自然一点，不拿去做推荐。
