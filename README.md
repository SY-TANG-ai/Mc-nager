# 职业"金"理人 · Mc-nager

> **"喜欢您来！"**

给无聊得把手机翻遍的你。

不一定是懒。也许是心里有件说不清的事，动力不太够，又说不上来哪不对。

来麦当劳坐坐吧。

（什么，去不了实体店？）远处金色的 M 还亮着，那你叫一声——职业**"金"理人**就来了。

---

## 这是什么

Mc-nager 是一个 Agent Skill。装上它，你的 Agent 会化身**麦当劳职业"金"理人**，用麦当劳的语气陪你在赛博麦当劳坐一会儿。

**它不是客服，也不是点单机器人。**

| | |
|---|---|
| 它做什么 | 招呼你、陪你说话、听你吐槽、给你递点吃的 |
| 它怎么说话 | 学麦当劳官方微博的腔调——短句、留白、偶尔傲娇 |
| 它记得你 | 聊过的话会记在本地档案里，下次接着聊，多来几次，会变成熟客 |

---

## 安装

### 第 0 步 · 准备

- 一个支持 Skill 的 Agent。**推荐 [WorkBuddy](https://www.workbuddy.cn)**（本项目全程在它里面开发和测试）
- Python 3.8 以上，用于生成语气样本（脚本是纯标准库，不用装任何包）

### 第 1 步 · 装 Skill

**最省事的方式**：把这个仓库的链接发给你的 Agent，说一句——

> 帮我装这个 skill：https://github.com/SY-TANG-ai/Mc-nager

**手动装**：

```bash
git clone https://github.com/SY-TANG-ai/Mc-nager.git

# 用户级：所有项目都能用
cp -r Mc-nager ~/.workbuddy/skills/

# 或者项目级：只在当前项目可用
cp -r Mc-nager <你的项目>/.workbuddy/skills/
```

Windows 用户如果没有 `cp`，直接把整个目录复制到 `%USERPROFILE%\.workbuddy\skills\Mc-nager\` 即可。

**装完确认一下**：目录里应该有 `SKILL.md`。Agent 靠这个文件认识它。

### 第 2 步 · 接麦当劳 MCP（可选，但强烈建议）

不接也能聊，接了它就知道你爱吃什么、最近店里在忙什么，还能真的帮你下单。

1. **申请 Token**：打开 <https://open.mcd.cn/mcp> → 手机号登录 → 右上角控制台 → 激活
2. **写配置**：把 Token 填进 `~/.workbuddy/mcp.json`（照抄 `mcp-config.example.json` 的结构）

```json
{
  "mcpServers": {
    "mcd-mcp": {
      "type": "streamable-http",
      "url": "https://mcp.mcd.cn",
      "headers": {
        "Authorization": "Bearer 换成你自己的Token"
      }
    }
  }
}
```

3. **重启会话**，让它生效

> 仓库里的 `mcp-config.example.json` 只有占位符，**没有任何真实凭据**。你的 Token 不要提交到任何地方。

接上之后，它会去翻你的历史订单、看最近的活动日历、对一下当前时间——开场那句"最近在忙什么"就是真的了。

### 第 3 步 · 验证装好了

新开一个会话，随便说一句：

> 好想吃麦当劳

如果它**以经理的身份开口**——招呼你、说自己手上正忙着什么、问你今天怎么样——那就是好了。

如果它**开口第一句就是"请问需要点什么"**，或者二话不说甩你一份价格表——那是没加载上。正常的开场永远是先招呼你、顺手提一句自己正忙着什么，然后才问到你。

检查一下 `SKILL.md` 是不是在正确的位置，然后重开会话。

## 使用

不用记命令，说人话就行。

| 你说 | 会发生什么 |
|---|---|
| `好想吃麦当劳！` | 经理开门迎客，先跟你打招呼 |
| `去麦当劳坐坐` | 同上，偏闲聊 |
| `找金理人聊聊` | 同上 |
| `一个人有点闷` | 它会换一套声音，安静地陪你待一会儿 |
| `帮我看看附近哪家店开着` | 有 MCP 就真去查，没有就告诉你怎么查 |

**第一句别提"有什么吃的"。** 那是点单，不是聊天。它想先看看你几点来、上次说过什么、今天店里在忙什么，然后才开口。

想聊什么都可以——今天倒霉的事、写不完的作业、突然想吃的东西。它不会催你点单。

### 它需要什么

| 依赖 | 必需 | 说明 |
|---|:--:|---|
| Python 3.8+ | 是 | 跑 `scripts/sample_corpus.py` 生成语气样本 |
| 麦当劳 MCP | 否 | 没有也能聊，只是不知道你的历史和最近活动 |

## 它记得你说过什么

每次聊完，它会往 `memory/guest.md` 里追加一段：你怎么称呼、常来时段、聊到过什么、它答应过你什么、哪句话没说完。

下次你再来，开场就能用上。

> 这个文件**只存在你本地**，被 `.gitignore` 排除，不会进仓库，也不会上传。

## 关于那份语料

它的说话方式不是凭空写的，是从麦当劳官方微博里学来的。

- `corpus/weibo-corpus.jsonl` 收录 **586 条**官微公开博文，时间跨度 2025-11 至 2026-10
- 抓取后做了清洗：去掉转发、置顶、纯图，去掉含价格符号、具体日期时间的条目，并截掉了抽奖话术的尾巴
- **只学说话方式，不搬原句。** `SKILL.md` 里明确禁止直接引用微博原文

`corpus/weibo-sample.jsonl` 是从中按月加权抽样的 120 条，供 Agent 每次加载时用。它由脚本生成、不进仓库：

```bash
python scripts/sample_corpus.py            # 默认 120 条
python scripts/sample_corpus.py --n 60     # 只抽 60 条
python scripts/sample_corpus.py --seed 7   # 复现某一次抽样
```
